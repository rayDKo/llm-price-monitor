# LLM Price Monitor

Веб-приложение для мониторинга цен на модели LLM у различных провайдеров.

## Возможности

- **Множество провайдеров**: OpenRouter, Ollama (локально), Generic HTML scraping
- **Выбор моделей**: Чек-лист моделей за каждым провайдером, сохраняется в localStorage
- **История цен**: Графики изменений цен за 7/30/90 дней (Chart.js)
- **Алерты**: Браузерные уведомления при изменении цены
- **Авто-обновление**: Настраиваемый интервал (5 мин – 1 час), пауза при скрытой вкладке
- **Экспорт**: CSV / JSON текущих цен и истории
- **Импорт/Экспорт конфига**: Перенос настроек между устройствами
- **Тёмная тема**: Системная / светлая / тёмная
- **PWA**: Установка как приложение, офлайн-работа (IndexedDB)
- **Без бэкенда**: Полностью клиентское, данные хранятся локально

## Добавление провайдеров

### OpenRouter (встроен)
Автоматически загружает все модели с ценами через публичный API.

### Ollama Local (встроен)
Подключается к `http://localhost:11434`, показывает установленные модели как бесплатные.

### Generic HTML (настраиваемый)
Для любого сайта с таблицей цен:
1. Нажмите «+» → выберите «Generic HTML»
2. Укажите URL страницы с ценами
3. Задайте CSS селекторы:
   - **Строка модели**: `table tbody tr` или `.model-row`
   - **Имя модели**: `td:first-child` или `.model-name`
   - **Цена входа**: `td:nth-child(2)`
   - **Цена выхода**: `td:nth-child(3)`
   - **Контекст** (опц.): `td:nth-child(4)`

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `R` | Обновить цены |
| `M` | Открыть выбор моделей |
| `S` | Настройки |
| `Esc` | Закрыть модалку |

## Приватность

- Все данные хранятся **только в браузере** (localStorage + IndexedDB)
- Никакие данные не уходят на внешние серверы
- API ключи не сохраняются (только публичные эндпоинты)
- Работает полностью офлайн после первой загрузки

## Деплой

### GitHub Pages
```bash
npm run deploy
```
Требует настройки GitHub Pages на ветку `gh-pages` (создается автоматически).

### Netlify / Vercel
Подключите репозиторий — сборка определится автоматически (`npm run build`, папка `dist`).

### Docker
```dockerfile
FROM nginx:alpine
COPY dist/ /usr/share/nginx/html/
EXPOSE 80
```

## Технологии

- **Alpine.js** — реактивность, состояние UI
- **Tailwind CSS** — стилизация (CDN)
- **Chart.js** — графики истории цен
- **Dexie.js** — IndexedDB обертка
- **Vite** — сборка и dev-сервер
